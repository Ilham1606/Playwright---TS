# Playwright TypeScript – Learning Notes

This repository is a personal learning space for exploring **Playwright with TypeScript**.

Nothing fancy here — just practice, experiments, and notes while trying to understand how things work in real test scenarios.

## What’s inside

- Basic Playwright setup with TypeScript
- UI testing examples
- API testing experiments
- Simple auth flows (token, headers, `/auth/me`, etc.)
- Trial-and-error configs and helpers

Some code might look basic or repetitive — that’s intentional while learning.

## Goal

The goal of this repo is to:

- Get comfortable with Playwright + TypeScript
- Understand test structure, not just make tests pass
- Learn by breaking things and fixing them

This is **not** a production-ready framework.

## Tech Stack

- Playwright
- TypeScript
- Node.js

## How to run

```bash
npm install
npx playwright install
npx playwright test
```
